# План дозаписи датасета

Основано на аудите текущего датасета: `432` пары JSON/TXT, `14696`
символов, `86` уникальных символов из `89` возможных.

## Что сейчас не хватает

Не встречаются вообще:

- `„` - нижняя открывающая кавычка;
- `4`;
- `6`.

Очень редкие символы:

- цифры: `5` - 1, `9` - 1, `0` - 2, `8` - 2, `3` - 3, `7` - 3,
  `1` - 4, `2` - 5;
- заглавные редкие: `Ъ` - 3, `Ы` - 3, `Ь` - 3;
- пунктуация: `!` - 12, `(` - 15, `)` - 15;
- заглавные на границе низкой частоты: `И` - 18, `Е` - 20, `Ж` - 20.

Дополнительно полезно усилить редкие русские буквы в обычных фразах:
`ф`, `х`, `ц`, `щ`, `э`, `ю`, `ё`.

## Как писать

- Начинай с номера `433`, если новые JSON будут добавляться после текущего
  датасета.
- Символ `\n` ниже означает реальный перенос строки в TXT и на экране.
- Для основного набора лучше писать вертикально.
- Горизонтальный режим использовать для длинных однострочных фраз.
- После каждых 20-30 новых примеров пересобрать и снова проверить аудит:

```bash
python scripts/handwriting.py dataset
python scripts/handwriting.py audit-dataset
```

## Приоритет

Если писать не всё сразу, порядок такой:

1. `433-452` - цифры.
2. `453-472` - нижние кавычки, скобки, редкие заглавные.
3. `473-492` - редкие русские буквы.
4. `493-502` - многострочные.
5. `503-507` - горизонтальный режим.
